# Fork 1B — Painbringer

> Slow and hard. Quality of suffering over quantity of hits. The null acid comes out. Attrition, make it last.
> A frontliner who applies compounding void-acid debuffs that self-stack without falling off, becoming a team force multiplier the longer a fight goes.
>
> **Trunk:** [Fucking Oni](./trunk.md)
>
> **Natural weapons:** 1H axe (hatchet/buffer), 2H blade (beast/stun-execute), fist arm (dirty), fist claw (gore/bleed)
>
> **SDP affinities:** Wizard, Vanguard

**Block size:** 20 (4 combat + 8–12 passive target, remainder spare)

---

## Debuffs (self-stacking, never fall off once applied)

| Name | Effect | Cap |
|---|---|---|
| Null Acid | ~2% current HP damage per tick per stack | 25 stacks |
| Tangling Shadows | −3 MSB per stack | 25 stacks |
| Corroding Resistance | +1 PDR/MDR per stack (benefits all allies attacking the target) | 50 stacks |

---

## Combat skills (4)

| # | Name | Description |
|---|---|---|
| 1 | Caustic Void | Small arc, short cooldown. Applies **Null Acid**. The engine — spam it constantly to start and maintain stacks. |
| 2 | Creeping Tendrils | Short, wide line, long cooldown. Heavy damage. Applies **Null Acid**. Also applies **Tangling Shadows** if target already has Null Acid. Rewards staying front and center. |
| 3 | Crashdown Cloud | Huge arc, moderate cooldown. Moderate damage — but tremendous damage to targets already afflicted with Null Acid. Applies **Null Acid**. Also applies **Corroding Resistance** if target already has Null Acid. Rewards keeping targets afflicted; benefits the whole party via CR. |
| 4 | Flambé du Vide | **Signature.** Small arc, disgusting knockback, long cooldown. Damage scales with Null Acid stacks. Bonus damage for Tangling Shadows stacks. Bonus damage for Corroding Resistance stacks. The execute — use after all three debuffs are cooking. |
