## Saturation economy (row **4** + prof **7**)

| | |
|---|---|
| **Offchain press** | Applies **Saturation** stack(s) to self |
| **Per stack** | **+25% MAT** — **additive** |
| **Duration** | **~5s** per stack (refresh on reapply) |
| **Stack cap (base)** | **4** → max **+100% MAT** |
| **Stack decay** | **Let off the gas and stacks fall** — stop pressing offhand, ramp drops |
| **Offchain CD** | **~1s** baseline (tune at migration) |

**Prof 7 (Supersaturation):** each offhand press applies **4 stacks** (was **1**); cap **40** (was **4**) → theoretical max **+1000% MAT** (**10×**) after **ten** offhand executions at cap.

**Trade-off (intentional):** **DBZ powerup** vs **weave** — sit in back stacking for ~half a minute while allies work, or pepper offhand between **pew** strings. Class **spells** ( **~1–5s** cast) get **maybe one or two** casts per window — you probably don’t need max stacks to delete heads with bullets alone.

**Not channeling:** offhand is **press → apply** (same family rule: no hold behavior except guard/dash).

### Alienation — enemy typing (not “tags”)

- **`anti-*` family elements** match the enemy’s **single family** (undead / construct / deity).
- **`x-aura`** is a **slayer-trait element** — hits enemies carrying that **x-*** trait (enemies may have **0–4** such traits; family and traits are separate axes).
- Migration: **`attackElements`** on main rows — not a separate tag system.

## Loop (base)

**Pew** on **`freeCombo`** → tap **Saturation** to stack **MAT** → **pew** harder (or cast **1–2 spells** in window) → stacks fall if you stop maintaining → repeat. Prof adds **volume**, **homing**, **stack ceiling**, **typing**, **bullet hell**.

## Archetype partners (draft)

**Natural:** Enchanter, elemental panels, any **MAT**-lean build — wand buffs **weapon bolts and kit magic** for the same short window.
