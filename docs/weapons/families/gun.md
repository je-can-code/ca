## Family thesis

**Gun is two buttons with different jobs** — how each subgroup splits **main** vs **offhand** defines the kit.

| Subgroup | Main | Offhand |
|---|---|---|
| **Pistol** | Melee combo → **Gun-fu** stacks | TP shots; **B** consumes stacks |
| **Taser** | Pin → flip → **mash** (history ramp) | **Nuke** off-chain |
| **Shotgun** | **`freeCombo`** spread + bleed / knockback | **Reload** → shell stacks buff main |
